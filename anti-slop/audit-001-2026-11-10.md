## HIGH (Hard Gate)

### 1 — Em dash (`—`) everywhere (R-02)
Banned character in every text the agent writes.
- `src/app/layout.tsx:24`, `:39` — metadata title `${APP_NAME} — ${APP_TAGLINE}`
- `src/app/page.tsx:21` — feature copy "five complete projects — not random words"
- `src/app/page.tsx:79` — "from real projects — so your fingers keep up"
- `src/app/about/page.tsx:57` — "you actually write — so your muscle memory"
- `src/components/layout/footer.tsx:12` — "TypeStack — built for developers who type all day"
- `src/features/typing/lib/grade.ts:33` — grade blurb "Sharp and consistent — great run"
- `README.md:1,4,5,12,17,19,21,22,23,37,88-92,98` — 15 lines
Fix: replace with `,` `.` `:` or `()`.

### 2 — Eyebrow pill above the H1 (R-09)
`src/app/page.tsx:57-62`. Pill + thin border + small dot directly above the headline, holding a category label. R-09 forbids it as decoration.

### 3 — No design direction / not labeled draft (R-37)
No `DESIGN.md`, no `CLAUDE.md`/`AGENTS.md` brand guidance in repo. Design built without direction and not labeled *"draft without direction"*, no dials declared.

### 4 — Interactive elements lack `cursor: pointer` + accessible names (R-39)
- No base CSS `cursor: pointer` for `a[href]`/`button`/`summary`/`select`. Only the `Switch` sets it inline.
- `src/components/ui/switch.tsx` — `role="switch"` with `aria-checked` but **no accessible name**; adjacent `<p>` label in `settings/page.tsx` is not linked by `id`/`aria-labelledby`.
- `settings/page.tsx` range `<input type="range">` has no `<label>`.
- `session-header.tsx` Restart/Exit icon buttons use `title` only, no `aria-label`.
- `typing-session.tsx:141` wrapper `div onClick={focus}` and `completion-modal` backdrop `div onClick` are clickable non-native elements.

### 5 — Contrast below WCAG AA (R-25)
- `typing-area.tsx`: pending characters rendered at `opacity: 0.4` over `--card`; `--syntax-plain` light `oklch(0.3)` dimmed to 40% ≈ 2.5:1 on white. Normal text → fail (need 4.5:1).
- `typing-area.tsx` line numbers `text-muted-foreground/50` — 50% grey, fail.
- `--syntax-comment` light `oklch(0.6 0.02 145)` at full opacity ≈ 3.5:1 on white, borderline fail.

### 6 — Missing UI states (R-27)
Data views ship only the happy path:
- `result/page.tsx` history list has an empty state but no **loading** or **error** state.
- `projects/page.tsx` completion state reads persisted store with no loading state (may flash "not done" before hydration).
- `settings/page.tsx` has a `mounted` skeleton (good), but no error state.
Local-only storage lowers the risk; still a gap by the rule.
